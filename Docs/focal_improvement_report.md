# RoBERTa 三分类改进实验总结

## 1. 背景

三分类文本分类任务：安全 / 质量 / 其他。前期最优结果为联合调参后的 `RoBERTa + SupCon + CLS`：

| 指标 | 结果 |
|---|---|
| Test Accuracy | 82.86% |
| Test Macro-F1 | 81.66% |
| 安全 F1 | 75.47% |
| 质量 F1 | 87.85% |
| 其他 F1 | 81.67% |

数据规模：训练集 270 条（三类各 90），测试集 140 条（24/53/63）。

前期报告已指出主要瓶颈：**训练集和测试集之间"安全"与"其他"的标注口径差异**。

## 2. 实验总览

| 序号 | 实验 | Test Acc | Macro-F1 | 安全 F1 | 关键改动 |

| 0 | joint_tuned (基线) | 82.86% | 81.66% | 75.47% | CE + SupCon |
| 1 | ProtoSupConLoss | ~82% | — | — | 原型对比，无效 |
| 2 | focal λ=0.1 | **85.00%** | **84.26%** | **80.77%** | FocalLoss 替 CE |
| 3 | focal λ=0.05 | 81.43% | 80.94% | 78.57% | 降对比权重，退步 |
| 4 | focal + FGM eps=0.5 | 85.00% | 83.58% | 76.36% | 扰动太小/无影响 |
| 5 | focal + FGM eps=1.0 | 83.57% | 82.14% | 75.00% | 有害 |

### 2.1 FocalLoss γ 参数扫描

固定 λ=0.1，扫描 γ ∈ {0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 4.0, 5.0}。

| γ | Test Acc | Macro-F1 | 安全 F1 | 其他→安全 | 备注 |
|---|---|---|---|---|---|
| 0.5 | 83.57% | 82.95% | 80.00% | 8 | γ 太小，接近 CE |
| 1.0 | 84.29% | 83.45% | 78.57% | 9 | |
| 1.5 | 84.29% | 83.41% | 78.57% | 9 | |
| **2.0** | **85.00%** | **84.00%** | **79.25%** | **7** | **最优** |
| 2.5 | 82.86% | 82.19% | 79.25% | 7 | 开始过拟合 |
| 3.0 | 82.14% | 80.93% | 75.47% | 8 | |
| 4.0 | 80.71% | 79.80% | 74.58% | 9 | 过度关注噪声 |
| 5.0 | 82.86% | 81.76% | 76.36% | 8 | |

趋势：γ 从 0.5 到 2.0 逐步提升，到 2.0 达到峰值，之后随 γ 增大而下降。γ=2.0 恰好平衡——给难样本足够权重，又不至于把标注噪声当信号放大。γ=4.0 时性能退化到比 CE 还差（80.71% vs 82.86%），说明过度聚焦少数难样本反而伤害整体分类。

### 2.2 最终最优方案

### 3.1 FocalLoss γ=2.0 是最优配置（+2.14pp）

替换 CrossEntropy 为 FocalLoss (γ=2.0)，让模型聚焦低置信度样本（即"安全"/"其他"边界上的难例）。γ 参数扫描（§2.1）确认 γ=2.0 最优——太小则退化为 CE，太大则过度关注噪声样本。效果：

- "其他→安全"误判从 **9 条降至 5 条**（-44%）
- 安全 precision 从 66.67% → 75.00%（+8.33pp）
- 安全 F1 从 75.47% → 80.77%（+5.30pp）

### 3.2 为什么 ProtoSupConLoss 无效

ProtoSupConLoss 的核心价值是"batch 内某类正样本不足时用原型弥补"。但本任务三分类、数据均衡、batch_size=16、平衡采样后每类约 5 条/批——正样本充足，原型支路不解决实际瓶颈。

### 3.3 为什么 FGM 有害

FGM 在 embedding 上加扰动，适用于**分类边界清晰**的场景。本任务"安全"和"其他"标注边界模糊，扰动反而搅乱模型判断，导致安全 precision 暴跌（80.77% → 71-76%），"其他→安全"误判回升。

### 3.4 全量训练不如留验证集

270 全量 vs 216+54 分割，前者多了 54 条训练数据但丢了验证集选 epoch 的能力，最佳轮次的 Test Acc 从 85.00% 降到 84.29%。

### 3.5 85% 是当前数据天花板

错误分析显示：21 条错误中 **13 条（62%）是"其他"被误判**。抽查这些样本发现：

| 文本片段 | 人工标注 | 模型预测 | 语义判断 |
|---|---|---|---|
| "隔离措施不足" | 其他 | 安全 | 更接近安全 |
| "配电箱破损未修复" | 其他 | 安全 | 更接近安全 |
| "未设警示围护" | 其他 | 安全 | 更接近安全 |
| "配合比设计无计算过程" | 其他 | 质量 | 更接近质量 |
| "螺栓安装数量不足" | 其他 | 质量 | 更接近质量 |

模型在这些样本上的判断**语义上合理**，但和人工标注不一致——说明问题在标注口径而非模型能力。

## 4. 最优配置

```bash
python src/train.py --config configs/roberta_supcon_focal.yaml 
```

## 5. 后续方向

模型侧改进空间已基本耗尽。如需突破 85%，建议从数据侧入手：

1. **修正标注口径**：重点清理"其他"类中语义上属于安全/质量的样本
2. **五折交叉验证 ensemble**：已有 `train_kfold_ensemble.py`
3. **数据增强**：对边界样本做回译增强，扩充训练集

## 6. 对照基线

| 层级 | 方法 | Test Acc |
|---|---|---|
| 词袋 | 结巴分词 + 词命中率 | 64.29% |
| 词袋 | 结巴分词 + TF-IDF 余弦 | 75.00% |
| 预训练 | RoBERTa + CE | 80.00% |
| 预训练 | RoBERTa + CE + SupCon (joint_tuned) | 82.86% |
| 预训练 | **RoBERTa + FocalLoss + SupCon (最优)** | **85.00%** |

从词袋到预训练涨 5pp，从 CE 到 FocalLoss 涨 2pp。
